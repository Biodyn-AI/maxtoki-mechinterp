# Audit report — projects/maxtoki/ — 2026-05-07

Applies the recurring-issue catalogue from
`pipelines/audit-recurring-review-issues.md` (P1–P10) to all 8 pipeline runs
under `projects/maxtoki/runs/`.

The audit consumed: each run's `FINAL_SUMMARY.md` (mirrored in `summaries/`),
each run's `README.md` (scope statement), the project-level
`README.md` (cross-pipeline synthesis), and selected `outputs/*_summary.json`
+ `scripts/*.py` files where the markdown layer's claim required deeper
verification. No re-runs were performed.

---

## Executive summary

**8 runs audited:** spectral-geometry-217M, attention-grn-217M (4 datasets),
sae-atlas-217M (Stage 1 SAE atlas), circuit-tracing-217M (Stage 2),
exhaustive-mapping-217M (Stage 3), manifold-discovery-217M, topology-141-217M,
longevity-mechinterp-217M.

**Headline finding.** The maxtoki project's runs are, on average, **markedly
more rigorous** than the typical reviewer-flagged baseline. Patterns P1
(null/chance baseline), P3 (endpoint–object mismatch), P5 (selection-driven
inflation), P9 (causal language), and P10 (reproducibility) are well-handled
across most runs — most summaries explicitly cite their null structure, and
many runs cross-reference each other for triangulation. Two runs in particular
(manifold-discovery-217M and longevity-mechinterp-217M) are **gold-standard
exemplars** that raise the project bar for P4 (donor-held-out splits,
inference unit) and P6 (negative controls / pipeline-sensitivity gates).

**Persistent residual exposure** concentrates in three patterns:
- **P6** — *no run has a synthetic-graph positive control.* Negative findings
  rest on cross-pipeline coherence and on internal positive-control proxies.
  This is the largest reviewer-flagged gap that could be raised against any
  paper based on this project.
- **P4** — *most runs except manifold-discovery and longevity-mechinterp do
  not enforce GroupKFold or donor-held-out structure where the inference unit
  warrants it.* topology-141, sae-atlas, circuit-tracing, exhaustive-mapping
  use per-pair / per-feature CV without grouping by shared endpoints.
- **P8** — *single-seed / single-threshold / single-hyperparameter is the
  default.* Few runs report bootstrap CIs or threshold sweeps on headline
  numbers. attention-grn-217M is the only consistent exception.

**Counts by severity** (across all 8 runs × 10 patterns = 80 cells):
- **Clean / acknowledged-and-handled:** 49 (61%)
- **Acknowledged with gap / partial:** 23 (29%)
- **Unaddressed / flagged for action:** 8 (10%)

The 8 "unaddressed" cells correspond to 6 distinct action items, listed in
§Action proposals at the bottom.

**Cross-pipeline triangulation strengths** (which collectively act as the
project's strongest meta-defense against P6 / P3 reviewer pushback):
- 5 independent pipelines (attention-grn, circuit-tracing CRISPRi,
  sae-atlas Phase 6/8, topology-141 H123, exhaustive-mapping triplets) all
  converge on the same negative verdict for fine-grained regulatory logic
  on MaxToki — using methodologically distinct probes. This convergence is
  itself a meta-control.
- The **representational positives** (spectral-geometry rank-compression,
  manifold-discovery H65 + 3 sweep manifolds, exhaustive-mapping trajectory
  steering, topology-141 Phase-11 cross-layer single-axis) are coherent: all
  describe coarse identity / trajectory / geometric structure, not regulatory
  mechanism. This split is internally consistent and is itself a positive
  finding for the project.
- **Cross-architecture triangulation** (added 2026-05-07 to topology-141
  Phase 4 vs scGPT) reveals a load-bearing project-wide caveat: cross-model
  CCA alignment with Geneformer V2-316M holds (Pearson 0.382, p=0; CCA
  r=0.78) but **does not generalize across architectural families** —
  MaxToki vs scGPT yields CCA r=0.40, pairwise Pearson ≈ 0. Project-level
  language about "what MaxToki encodes" needs the qualifier "within the
  autoregressive-Ensembl-tokenizer family".

## P1 — Null model / chance baseline

**Pattern.** Every quantitative claim should be anchored to a chance baseline
with stated null family.

| Run | Verdict | Evidence |
|---|---|---|
| spectral-geometry | clean | feature-shuffle null + permutation tests + cross-pair cell-type contamination control + L2-norm residualization. Phase 9d explicitly null (0/675 sig). |
| attention-grn-217M (×4) | clean — exemplary | curveball degree-preserving null + gene-only/random/all-genes baselines + Wilcoxon BH-corrected p-values everywhere. Most rigorous P1 handling in the project. |
| sae-atlas | acknowledged with gap | 12/13 phases replicate with explicit null comparisons. **Gap:** 0% TF-specificity headline lacks an explicit chance-distribution baseline (what's the random-target-set null?). |
| circuit-tracing | acknowledged with gap | thresholds \|d\|>0.5, consistency>0.7 stated. CRISPRi 54.6% directional accuracy is itself a null comparison. **Gap:** the headline 2.14M edges count is reported relative to paper's 52K (41× denser) without a degree-preserving null on edge density. |
| exhaustive-mapping | clean | activation-frequency filter scope-deviation noted; annotation-bias has Fisher's exact; α-saturation diagnostic. |
| manifold-discovery | clean — exemplary | paired null at every Phase 0; quality gates frozen at Phase 0 and never relaxed. Within-branch shuffle null fails decisively across runs. Phase-7 lung_nonhema negative control fails 3/4 gates. **Gold standard for P1 in this project.** |
| topology-141 | clean (post-2026-05-07) | strict max-null harness across 4 null families; Phase-12 H141 audit. After 2026-05-07 audit additions, every load-bearing claim has its null gap. |
| longevity-mechinterp | clean | n=100 permutation null; G1 gate explicitly enforces 0.05 above null. The fail itself is the finding. |

**Project-wide assessment:** strong. Two specific gaps to close: sae-atlas
TF-specificity null distribution; circuit-tracing edge-density null.

## P4 — Pseudoreplication / leaky CV / wrong unit-of-inference

**Pattern.** The unit of inference must match the claim. CV split, null,
and bootstrap should respect grouping (donor / TF / target / cell-type).

| Run | Verdict | Evidence |
|---|---|---|
| spectral-geometry | partial | 1500 HVG, 2000 cells. Phase 8 CKA across 3 cell-sample seeds is appropriate at the cell-sample level. **Gap:** "Cells" not stated as drawn from N donors; gene-level claims do not GroupKFold by chromosome / TF. |
| attention-grn-217M (×4) | partial | Per-pert evaluation, BH across perts. **Gap:** within-pert CV split is per-cell — does the CV split ensure no gene-target leakage across folds? Not specified in summary. |
| sae-atlas | partial — flagged | 500 K562 control cells; per-feature analyses; no GroupKFold by gene/TF. Phase 6 patches "50 richly-annotated features" — annotation overlap across features could shared-feature-leak in the patch evaluation. |
| circuit-tracing | partial — flagged | 200 K562 cells, 120 source features. Per-feature CV not specified. Edge-CV could leak shared-source-feature structure. |
| exhaustive-mapping | partial — flagged | 1000 features × 20 cells per feature. Cross-feature dependencies not GroupKFold-controlled. |
| manifold-discovery | clean — exemplary | **Donor-held-out splits explicit. Random / donor / branch holdout gates. External validation = strict non-overlap, 13 disjoint donors, verified zero overlap. Zero-shot = 12 disjoint donors.** Cell-level quantities tested at anchor (centroid) level. **Gold standard for P4 in this project.** |
| topology-141 | partial | Per-pair AUROC over 1308–2544 pairs, but pairs share endpoints. TF-disjoint and target-disjoint splits implemented; not always dual-axis disjoint. |
| longevity-mechinterp | clean — exemplary | Donor-held-out 5-fold CV. Permutation null over donors, not cells. **Gold standard for P4.** |

**Project-wide assessment:** weakest pattern in the audit. Five of eight runs
do not respect endpoint/feature grouping in CV. The two strong exemplars
(manifold-discovery, longevity-mechinterp) demonstrate the project knows how
to do this properly when the design demands it; the remaining runs likely
inflate effective N. **This is the most actionable gap in the project.**

## Cross-pipeline triangulation observations

These observations only emerge by reading runs in conjunction. Several have
project-level implications.

### CT1. Convergent negative on regulatory logic (project-level positive defense)

Five runs reach the same negative verdict by methodologically distinct probes:
- attention-grn-217M (×4): curveball z ≈ 0; gene-variance baseline crushes attention.
- circuit-tracing-217M (Stage 2): CRISPRi 54.6% directional accuracy.
- sae-atlas-217M Phase 6/8: 1.01× causal specificity; 0% TF-specificity.
- topology-141-217M H123: 0–1/12 layers per domain pass null gap.
- exhaustive-mapping-217M Exp 2: zero higher-order synergy at 4 triplets.

This convergence is a **strong implicit positive control** and the project's
best meta-defense against P6 reviewer pushback. **Action: any paper drawing
on this project should explicitly state this multi-probe convergence as the
core evidential structure.**

### CT2. Coherent representational positives

The positive findings are all about coarse structure, not mechanism:
- spectral-geometry-217M: depth-wise rank compression replicates.
- manifold-discovery-217M: H65 hematopoietic developmental ordering + 3
  additional manifolds (H38 LITE signalling, H95 effector modality, H103
  B-cell maturation) all gate-passing.
- exhaustive-mapping-217M Exp 3: trajectory steering pushes toward maturity.
- topology-141-217M Phase 11 iter_04 (audit addition): H123 motif feature
  has cross-layer Pearson 0.60–0.68 — a single static axis across layers.

These four findings are coherent: MaxToki's residual stream encodes coarse
identity / trajectory / geometric structure. **The split (representational
positives + mechanistic negatives) is itself a finding.** Should be stated
plainly in any paper-level synthesis.

### CT3. Architectural-family scope (load-bearing project caveat)

The 2026-05-07 audit work on topology-141 (Phase 4 vs scGPT) revealed:
- MaxToki ↔ Geneformer V2-316M alignment: CCA r=0.78, Pearson 0.382 (p=0).
- MaxToki ↔ scGPT alignment: CCA r=0.40, pairwise Pearson ≈ 0 (slightly
  negative on immune, z=−3.0).

This is the project's most consequential **scope qualifier**. Anywhere the
project says "MaxToki and other foundation models agree on geometry", the
qualifier should be "within the autoregressive-Ensembl-tokenizer family;
agreement breaks across architectural families." Currently this qualifier
is in `topology-141-217M/EXTENDED_FINDINGS.md` and `FINAL_SUMMARY.md` but
**is NOT yet in the project-level `README.md`'s cross-pipeline synthesis.**

### CT4. The 0% TF specificity / 1.01× patching number deserves more triangulation

sae-atlas-217M reports:
- Phase 6 patching specificity 1.01× (paper Geneformer 2.36×) — non-replication.
- Phase 8 TF specificity 0% (paper 6.2%) — both models near floor.

These two findings are presented as architecturally consistent ("both models
near floor; MaxToki even more extreme"). But the absence of any paper
SCFM at >10% specificity means this isn't really a "MaxToki worse than
others" finding — it's a "no SCFM has been shown to encode TF specificity
above 10%" finding. The framing should sharpen to make this clear.

### CT5. Stage-2 → Stage-3 retroactive recontextualization is good practice

circuit-tracing-217M's Stage-2 used 30 annotation-quality-filtered features.
exhaustive-mapping-217M's Stage-3 traced 1000 features (500 random + 500
annotated) and found top-20 hubs are 55%/45% annotated/unannotated. Stage 3
**explicitly recontextualizes** Stage 2's Phase-6 1.01× specificity finding
as "selection-biased subset, not representative". This is a model for how
later runs should treat earlier runs — and similar retroactive checks should
be applied wherever Stage-2-style annotation-filtered selection was used.

## Residual exposure (what a future reviewer would still flag)

Even after all eight action items above are completed, the project remains
exposed to the following pattern instances. These are not feasible to fix
in a maintenance audit and should be acknowledged in any paper drawing on
this project rather than silently carried.

1. **No SCFM has been shown to encode regulatory logic above ~10% TF
   specificity at the per-feature level.** (P3) The project's negative on
   MaxToki should be stated as part of a *field-wide* pattern, not as a
   MaxToki-specific deficit. The sae-atlas wording already partially does
   this; project-level synthesis should follow.
2. **No proper cell-level Robust-V2 benchmark for manifold-discovery's H65
   manifold has been completed.** Phase 12 LITE is anchor-level only and
   already shows extracted head does not significantly beat
   PCA-10/SVD-10/frozen-MaxToki-avgpool baselines. The full cell-level
   benchmark with scVI / Palantir / CellTypist is multi-day work and is
   correctly deferred — but a paper claiming H65 is "deployable" should
   state this is at extraction-quality scope, not benchmark-superiority
   scope.
3. **The longevity-mechinterp G1 fail on a 17-donor cohort cannot be
   interpreted as evidence about MaxToki's age-encoding capacity.** This
   is well-handled in the run docs but inherits the source paper's structural
   issue: AIDA-scale (≥424 donors) is the regime where the strict gate is
   meaningful. A paper would need to clearly scope the negative.
4. **Single-seed extraction in topology-141 / sae-atlas / circuit-tracing /
   exhaustive-mapping.** Without re-extraction at multiple seeds, sensitivity
   to data sampling is unknown for these runs. attention-grn's 4-run grid is
   the only place where data-sampling stability has been tested.
5. **The H123 motif-community pipeline's cross-layer single-axis finding
   (topology-141 Phase 11 iter_04) is currently classified as "novel
   positive" but has not been replicated against a second tissue or a
   second model.** It should be replicated before entering any paper.
